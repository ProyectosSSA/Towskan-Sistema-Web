## 💡 Recomendaciones Técnicas:
1. **Formato:** JPG, PNG o WebP.
2. **Dimensiones recomendadas:** 600x600 px u 800x600 px (relación de aspecto cuadrada 1:1 o 4:3).
3. **Peso óptimo:** Entre 50 KB y 250 KB por imagen para garantizar carga ultrarrápida.
4. **Fallback:** Si alguna imagen aún no se ha colocado, la interfaz web mostrará automáticamente el emoji correspondiente sin romper el diseño.
